# Roadmap

## MVP

- Discover public archived streams.
- Store root stream assets.
- Analyze one stream with Gemini.
- Import native YouTube Ask responses.
- Validate and repair Gemini JSON.
- Persist multiple ranked candidates per stream.
- Review candidates in a local web UI.
- Rank top five candidates.
- Export CSV and JSON.

## Later

- Async worker queue.
- Harden native Ask browser automation across YouTube UI variants.
- Self-healing browser runner issue/PR loop for selector breakages.
- Direct Vizard API integration.
- Reanalysis prompts for new editorial questions.
- Publishing records and performance imports.
- Duplicate detection.
- Strategy layer over exported database records.
